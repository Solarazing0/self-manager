# Контекст проекта для агента

Перед работой с этим проектом обязательно прочитай и применяй [скилл разработки](.agents/skills/self-manager-development/SKILL.md). Он закрепляет договор с автором: сначала вопросы и план, затем явное согласование, после этого реализация и проверка. Работай в `main`; commit и push согласованной работы выполняй самостоятельно.

1. Прочитай [README.md](README.md): это компактное введение в концепцию Self-Manager.
2. Для деталей, проверки требований и проектирования обратись к [CONCEPT.md](CONCEPT.md). Раздел 22 различает подтверждённые требования и инженерные предложения; раздел 21 содержит открытые вопросы.
3. При расхождении документов укажи противоречие и уточни решение у автора. Не трактуй сокращение в README как отмену требования из CONCEPT.
4. Различай экосистему Self, её первый модуль Self-Manager и интерфейс Legion.
5. Сохраняй полный цикл намерения: захват, согласование, организация, исполнение, восстановление и результат. Проверяй решения на конкретных жизненных сценариях.
6. Не выдавай предложенные сущности, архитектуру, этапы MVP или примеры настроек за утверждённые решения. До выбора технологий уточни необходимые свойства системы и объём первой реализации.
7. При новых решениях синхронизируй документацию и сохраняй различие между требованиями, предложениями и открытыми вопросами.
