# Локальный запуск Self-Manager

## Открыть приложение

На Windows понадобится Node.js 24.14 или новее. В папке проекта выполни `npm.cmd ci`, затем `npm.cmd start` и открой [Self-Manager](http://127.0.0.1:4317). Остановить приложение можно через Ctrl+C в окне запуска.

Первый запуск создаёт `data/self.sqlite`. Открой Legion, отправь мысль, выбери «Составить план» и заполни ожидаемый результат. При необходимости укажи окно времени. Затем подтверди предложение. Задача появится в «Планах», а назначенное окно — на выбранной дате экрана «Сегодня». Открой задачу, чтобы записать начало, фактический результат или предложить другое время. В «Планах» видны ожидающие решения предложения.

Занятые окна вводятся вручную. Поиск первого свободного окна учитывает длительность, срок, назначенные окна и зависимости. Для переноса за исходный срок укажи новый срок и причину. Срок и окно изменятся вместе после подтверждения. Если в плане несколько шагов, окна назначаются шагам. Следующие шаги можно добавлять по мере продвижения.

Для фиксированного события нажми «Занятое окно» и укажи время сборов, дороги и запас. Например, для лекции в 09:00 со сборами 15 минут, дорогой 20 минут и запасом 10 минут система резервирует время с 08:15. Legion напомнит выйти в 08:30, а с 08:35 предупредит о риске. Расчётный крайний выход — 08:40. Отметка «Вышел» прекращает напоминания о выходе. После начала события можно подтвердить, удалось ли добраться. Изменения и фактические отметки остаются в истории.

По умолчанию расписание отображается в часовом поясе `Europe/Moscow`. Поля даты и времени используют часовой пояс устройства. Если он отличается, форма это показывает. Для другого часового пояса скопируй `.env.example` в `.env` и измени `SELF_TIME_ZONE`.

## Подключить облачный Legion

Ручной режим работает сразу. Для облачного диалога скопируй `.env.example` в `.env`, впиши свой `OPENAI_API_KEY` и точный `LEGION_MODEL`, затем перезапусти приложение. Официальный API ID модели с названием GPT-6 Luna — `gpt-6-luna`. В проекте модель выбирается явно. [Документация OpenAI](https://developers.openai.com/api/docs/models/gpt-6-luna)

Когда облачный режим включён, Legion получает исходную мысль, последние сообщения выбранного обсуждения, актуальный контекст задач, занятые окна и недавние подтверждённые наблюдения. Оригинал сохраняется на ПК до обращения к облаку. При недоступности модели можно повторить запрос из чата или составить план вручную. Ключ хранится в окружении процесса, а файл `.env` исключён из Git.

Диктовка доступна в браузерах с поддержкой распознавания речи. Текст появляется в поле ввода для проверки перед отправкой. Способ распознавания определяет браузер.

## Создать и восстановить резервную копию

1. В папке проекта выполни `npm.cmd run backup -- C:\Backup\self-copy.sqlite`. Папка назначения должна существовать. Команда создаёт снимок SQLite и проверяет, что файл с таким именем ещё не существует.
2. Чтобы проверить копию отдельно, задай в PowerShell `$env:SELF_DB = 'C:\Backup\self-copy.sqlite'`, `$env:SELF_PORT = '4318'` и запусти `npm.cmd start`. Открой [проверочный экземпляр](http://127.0.0.1:4318) и сверь историю, планы и память.
3. Для переноса на другой компьютер возьми снимок и укажи путь к нему в `SELF_DB`. Настройки и ключ на новом компьютере задаются отдельно.

## Доступ с телефона

Приложение по умолчанию слушает только адрес этого ПК `127.0.0.1`. Подготовлены манифест, иконки и экран загрузки для установки как веб-приложения. Для телефона потребуется доступный с него HTTPS-адрес с аутентификацией перед приложением. При такой настройке прокси должен передавать исходный Host, а `SELF_PUBLIC_ORIGIN` должен совпадать с HTTPS-адресом. Установка на физическом телефоне пока не проверена.

## Фоновые уведомления

Нажми «Уведомления выкл.» в верхней части приложения и разреши уведомления в браузере. Настройка действует на этом устройстве. На iPhone Web Push доступен для приложения, добавленного на домашний экран. На другом устройстве требуется доступный HTTPS-адрес. [Документация Push API](https://developer.mozilla.org/en-US/docs/Web/API/PushManager) · [WebKit для iPhone и iPad](https://webkit.org/blog/13966/webkit-features-in-safari-16-4/)

Когда появляются активные напоминания, работающий ПК отправляет один сигнал через службу уведомлений браузера. Сигнал о риске опоздания отправляется с повышенной срочностью. На экран блокировки приходит общий текст без названий задач, заметок и времени. Для просмотра открой Self-Manager. Время и факт появления сигнала зависят от браузера и операционной системы. Подписку можно отключить той же кнопкой.

По умолчанию фоновая доставка приостановлена с 22:00 до 08:00 в часовом поясе приложения. Измени `SELF_QUIET_HOURS` в `.env`, если нужен другой интервал. Значение `off` отключает тихие часы. Во время паузы напоминания по-прежнему видны на экране дня.

Звонки и будильник требуют отдельного канала. Если связь с ПК пропадает, доступен экран приложения из кеша. Записи и изменения требуют связи с ПК.

## Проверки

`npm.cmd test` проверяет сквозное сохранение мысли, согласование и перенос, отсутствие автоматического завершения, исправление истории, повторное открытие базы и восстановление из снимка. Также проверяются отложенные намерения, память, зависимости, подбор окна, обратимое объединение, итог проекта и сбой облачной модели с подставным ответом. Проверки Web Push используют подставную доставку. Живой запрос к модели требует настроенного API-ключа.
